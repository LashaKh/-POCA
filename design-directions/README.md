# ÉPOCA Visual Directions

Open `index.html` through a local web server to compare the four concepts:

```bash
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173/design-directions/`.

## Options

1. `option-01-atelier-editorial.html` — warm, fashion-led, split editorial composition.
2. `option-02-gallery-monolith.html` — cinematic, architectural, immersive composition.
3. `option-03-collectors-index.html` — curatorial, product-first catalog composition.
4. `option-04-living-archive.html` — layered, expressive, archival composition.

All pages are standalone HTML/CSS/JavaScript concepts with local images. They use the same fictional sample catalog and clearly label it as sample content. Direction 03, Collector’s Index, is selected; the other pages remain archived exploration.

`previews/` contains reliable viewport captures used in visual QA. Files ending in `desktop-top`, `desktop-mid`, `tablet`, and `mobile` correspond to 1440px, 768px, and 390px checks.

Image provenance is recorded in `assets/SOURCES.md`.
