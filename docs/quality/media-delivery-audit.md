# Media delivery audit

Verified: 2026-08-26.

## Consumer inventory

| Consumer              | Source and access                                                                            | Layout/performance                                                                                                              | Text and failure policy                                                                                      |
| --------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Catalog cards         | Published rendition path only; originals are never selected by the public catalog projection | `next/image`, reserved 4:5 dimensions, responsive `sizes`, AVIF/WebP negotiation, lazy loading                                  | Reviewed product name is the alt text; missing or failed media becomes a localized, aspect-reserved fallback |
| Product gallery       | Published gallery rendition only                                                             | 1200×1500 reservation, mobile/desktop `sizes`, first gallery image is LCP priority; later selections retain the same stage size | Per-image reviewed alt text; controls are named; no “high-resolution” or zoom claim is made                  |
| Ingestion crop editor | Short-lived processed private preview, never `product-originals`                             | Explicit 800×1000 reservation, lazy/async decode, fixed 4:5 preview                                                             | Descriptive review alt; focal controls expose numeric output                                                 |
| Owner MFA QR          | Ephemeral Supabase data URI, never persisted by ÉPOCA                                        | Explicit 220×220 reservation and async decode                                                                                   | Decorative empty alt because the adjacent instruction and manual setup code provide the usable equivalent    |

## Renditions and isolation

- The deterministic recipe emits placeholder, thumbnail, square, 4:5 card, 3:4 gallery, 16:9 editorial, and 1200×630 social renditions with recorded checksum, crop, focus, dimensions, and recipe version.
- Public records expose only approved rendition object paths. `product-originals`, ingestion previews, return evidence, and import/export objects remain private and use staff/customer-scoped signed access.
- Responsive public images use `next/image` with width/height and `sizes`, so `srcset` and aspect reservation are generated by the framework. Failed URLs switch to the same-size fallback instead of leaving broken media.
- The product gallery changes renditions but does not advertise deep zoom or an original-size view. This is deliberate: protected originals are not a public delivery tier.

## Regression checks

`tests/unit/media/media-delivery.test.ts` inventories every JSX image consumer and rejects a new raw image consumer until its access, sizing, loading, and alt policy is reviewed. Existing media pipeline and visual tests continue to validate recipes, crop math, public cards, and gallery reflow.
