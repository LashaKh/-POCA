## Success-criteria boundary

- **SC-011:** Catalog-specific pgTAP and integration checks prove anonymous/customer denial, Manager command access, private file ownership, forced RLS, and removal of direct browser table writes. The complete Buyer/Manager/Owner/stale-session matrix belongs to US8 and is not yet claimed.
- **SC-016:** This slice currently passes format, lint, types, 342 database assertions, 121 application tests, its critical manager journey, five accessibility projects, migration/type drift, and optimized build. Whole-release promotion remains closed until later access, security, recovery, and deployment gates pass.
- **SC-017:** Immutable catalog revisions, storage identities, and relational constraints make restoration verifiable, but a real backup/restore rehearsal is intentionally deferred to US11. No recovery-time or complete-restore claim is made here.

## Activation boundary

Catalog operations are complete against local fixture services. Production still requires rotated Supabase credentials, linked remote migrations and Storage buckets, an initial MFA-protected Owner, operational cleanup/backup jobs, production content, and controlled Netlify staging evidence.
