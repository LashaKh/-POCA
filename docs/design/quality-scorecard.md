# ÉPOCA UI Quality Scorecard

Use this after a browser render. `Pass` requires observable evidence; `N/A` needs a reason.

| Area          | Pass condition                                                                                                                                     |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Direction     | The surface clearly follows the selected `DESIGN.md` direction rather than a generic storefront template.                                          |
| Journey       | The visitor can identify the page purpose, primary action, and next step without guessing.                                                         |
| Product truth | Relevant price, dimensions, material, condition, availability, delivery, or policy information is present or explicitly deferred—never fabricated. |
| Composition   | Hierarchy, whitespace, image crop, and rhythm work at 390px, 768px, and 1440px.                                                                    |
| Content       | Headings are meaningful; labels and copy survive realistic long text without collision or clipping.                                                |
| Navigation    | Entry, continuation, cancellation/back, and recovery paths are clear.                                                                              |
| States        | Loading, empty, error, unavailable, success, missing-media, hover, focus, and pressed behavior are intentional where relevant.                     |
| Accessibility | Semantic structure, keyboard order, visible focus, contrast, non-color cues, touch targets, alt text, and reduced motion are verified.             |
| Performance   | Images are right-sized and lazy below the fold; space is reserved; unnecessary libraries and motion are absent.                                    |
| Integrity     | Imagery is attributable and there are no invented reviews, press, awards, scarcity, discounts, provenance, or sustainability claims.               |
| Restraint     | No gratuitous glass, gradients, pills, shadows, bento grids, smooth scrolling, animation, or WebGL.                                                |
| Evidence      | Render captures and targeted tests support the review, with remaining defects named plainly.                                                       |
