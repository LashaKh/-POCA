# Audit ÉPOCA UI

Use `.agents/skills/epoca-storefront-design/SKILL.md` and score against `docs/design/quality-scorecard.md`.

1. Read product, design, feature, and implementation context before judging the surface.
2. Render the real interface at 390px, 768px, and 1440px. Also inspect keyboard navigation, visible focus, reduced motion, long content, missing media, and relevant loading/empty/error/unavailable/success states.
3. Check direction fidelity, journey clarity, product truth, responsive composition, accessibility, performance, content integrity, and visual restraint.
4. Rank findings as CRITICAL, HIGH, or MEDIUM and cite observable evidence. Give a concrete correction for each finding.
5. If edits are authorized, fix the smallest set of root causes, then re-render affected views for the second and final pass.
6. Do not self-certify from source code alone or add unsupported product claims while polishing copy.
