# Shape ÉPOCA UI Direction

Use `.agents/skills/epoca-storefront-design/SKILL.md` as the workflow authority.

1. Read `PRODUCT.md`, `DESIGN.md`, `docs/design/WORKFLOW.md`, and relevant feature artifacts completely.
2. Inspect existing UI and media before proposing a new vocabulary.
3. Classify the page mode and state the visitor's goal.
4. Produce a concise art-direction brief: emotional goal, composition, imagery, typography, palette, density, rhythm, primary action, product truth, states, and phone/tablet/desktop adaptations.
5. Separate known product facts from assumptions needing validation.
6. When implementation is requested, create a code-native browser concept using attributable imagery and the static-first, reduced-motion rules in the skill.
7. Do not edit `DESIGN.md` to mark a direction selected until the user chooses it.
